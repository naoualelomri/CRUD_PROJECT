#  Projet WebCRUD – Gestion d’un magasin de plantes

Ce projet est un site web  permettant de gérer un magasin en ligne de plantes. Elle permet d’ajouter, modifier, supprimer et consulter des plantes via une interface conviviale. Ce projet a été réalisé dans le cadre du module de développement web.



# Fonctionnalités

-  Affichage des plantes : Liste de toutes les plantes enregistrées.
- Recherche de plante : Recherche rapide par nom.
- ajout d'un client : à travers un formulaire a remplir.

# Technologies utilisées

- **Frontend** : HTML5, CSS, JavaScript vanilla
- **Backend** : Node.js, Express.js
- **Base de données** : MySQL
- **Autres** : Postman pour les tests des routes API
